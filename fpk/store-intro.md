# Hotify Server — 把所有消息装进你自己的 NAS

> 自托管的多设备消息与推送服务器：手机、电脑、服务器、家里的设备，一个地址全收到；消息、图片、文件，全部只存在你自己的机器上。

---

## 你可以用它做什么

**📱 服务器出事，手机第一个知道**
Uptime Kuma、Home Assistant、脚本任务的告警，推一个地址就到所有设备的锁屏上——iPhone 装 Bark App 直接收，鸿蒙设备走华为系统级推送，锁屏可达、应用被杀也送达。

**💬 短信验证码全设备同步**
SmsForwarder 转发的短信，手机电脑平板同时到，谁发的清清楚楚（消息带来源标识）。

**📤 设备之间传文件**
手机拍的视频直接推给电脑，单次最大 4GiB——不用数据线，不用网盘，不经第三方云。

**🗂️ 所有消息一处留档**
换手机、重装系统，历史消息和「读到哪了」的进度都还在，多台设备自动同步。

---

## 特性

- 📨 **消息统一管理** — 全设备消息服务端留档，多端阅读进度同步，网页随时翻
- 📲 **全平台都能收** — iPhone 装 Bark App 收离线推送，Windows / 安卓接 gotify 客户端（实时收+翻历史），鸿蒙走华为系统级通道
- 🔔 **离线也必达** — 华为系统级推送锁屏可达、应用被杀仍送达；在线走 WebSocket 实时收，两路互补不丢消息
- 🔌 **现成工具直接用** — 短信转发器（SmsForwarder）、Uptime Kuma 换个推送地址就行
- 🖼️ **媒体直传** — 图片 / 音频 / 视频 / 文件与文字同一接口，全程流式不占内存，配好域名后通知里直接显示图片
- 🖥️ **网页管理台** — 浏览器打开 /console：设备增删改名、在线状态、文件浏览器（按图片/视频/音频/文件分桶带缩略图）、一键备份、改密码
- 🏠 **数据 100% 自有** — 单二进制内嵌数据库，零外部依赖；所有数据一个目录，拷走即迁移，一条 curl 不停机整库备份
- 🧹 **磁盘不会涨爆** — 超过上限（默认 16GiB，可配）自动淘汰最旧内容
- 🚀 **三十秒起步** — 浏览器打开 /setup 设个密码就能用；新设备远程接入免抄密钥

## 兼容生态

**fnOS 应用中心直接装、通知原生可配**（填你的 Hotify 地址即可）：

- **Uptime Kuma** — 通知类型选 Bark 或 Gotify（监控告警）
- **Sonarr / Radarr / Jellyseerr** — Connect/通知选 Gotify（追剧追影到货、家人点片）
- **MoviePilot** — 通知渠道选 Bark（影视自动化）
- **青龙面板** — 通知设置选 Bark / 自定义（脚本任务）
- **Home Assistant** — bark 集成 / REST 通知（全屋自动化）
- **n8n / Node-RED** — HTTP 节点指向本服务（工作流）
- **ddns-go / certimate** — Webhook / Bark（DDNS 变更、证书到期）

**手机与收端**：

- **短信转发器（SmsForwarder）** — Webhook 地址换成你的服务器
- **iPhone Bark App** — 添加服务器地址即收离线推送
- **gotify 客户端（Windows / 安卓）** — 服务器地址 + 密码直接登录，实时收+翻历史

以及**一切支持 Bark / Gotify / Webhook 通知的软件**——NAS 生态里带「通知设置」的应用基本都在内。ntfy 发布亦支持（`PUT /ntfy/{topic}`）。
